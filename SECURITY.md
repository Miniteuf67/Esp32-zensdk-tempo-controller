# Sécurité

Ce projet est prévu pour un LAN privé et ne doit pas être exposé directement sur Internet.

- L'interface Web locale utilise HTTP.
- Le mot de passe administrateur et les identifiants Wi-Fi sont stockés en NVS.
- Les écritures Zendure sont désactivées par défaut.
- Ne réutilisez pas le mot de passe admin sur un autre service.
- Signalez les vulnérabilités sans publier de secrets ni de numéros de série réels.
