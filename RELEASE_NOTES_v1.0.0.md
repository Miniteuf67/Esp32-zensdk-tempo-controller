# v1.0.0 — Première version publique

Première version GitHub du Zendure Tempo Controller.

Points principaux :

- dashboard énergétique autonome sur ESP32 ;
- Zendure SolarFlow + Shelly Pro 3EM + F1ATB ;
- Tempo RTE et météo Open-Meteo en HTTPS ;
- historique 24 h avec graphique optimisé ;
- paramètres persistants et portail Wi-Fi de secours ;
- pilotage F1ATB générique par numéro d'action ;
- commandes Allumer 30 min / Éteindre 30 min / Annuler ;
- lecture du forçage F1ATB en cours ;
- OTA Web et diagnostics locaux.
